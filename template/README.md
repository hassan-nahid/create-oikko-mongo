## 🚀 Getting Started

### 1. Prerequisites
- Node.js >= 18.0.0
- MongoDB instance (local or MongoDB Atlas)
- Redis server (optional, for caching & token blacklisting)

### 2. Installation
```bash
npm install
# or pnpm install / yarn install / bun install
```

### 3. Environment Setup
Review and configure your `.env` file (copied automatically from `.env.example` with auto-generated secure secrets):
```env
PORT=5000
DB_URL=mongodb://localhost:27017/{{PROJECT_NAME}}
NODE_ENV=development
```

### 4. Run Development Server
```bash
npm run dev
```
The server will start listening at `http://localhost:5000`.

### 5. Build & Production Run
```bash
# Build TypeScript
npm run build

# Start production server
npm start
```

## 📁 Architecture & Directory Structure

This project follows **Modular Clean Architecture**:

```
src/
├── app.ts                  # Express application setup
├── server.ts               # HTTP server bootstrap & DB listeners
└── app/
    ├── config/             # Environment, DB, Passport & Redis configs
    ├── errorHelpers/       # AppError class
    ├── helpers/            # Error normalization helpers
    ├── interfaces/         # Global TypeScript declaration merging
    ├── middlewares/        # checkAuth, validateRequest, globalErrorHandler, etc.
    ├── modules/            # Business domains (auth, user, otp, etc.)
    ├── routes/             # Central route aggregator
    └── utils/              # Utilities (catchAsync, sendResponse, sendEmail, etc.)
```

## 🛡️ Default API Endpoints

- **Auth** (`/api/v1/auth`)
  - `POST /login` - User login
  - `POST /refresh-token` - Refresh access token
  - `POST /logout` - Logout & clear token cookies
  - `POST /forgot-password` - Request password reset
  - `POST /reset-password` - Reset password with token
  - `POST /change-password` - Change password (authenticated)
  - `GET  /google` - Google OAuth initiation
  - `GET  /google/callback` - Google OAuth callback

- **Users** (`/api/v1/user`)
  - `POST /register` - Register a new user
  - `GET  /me` - Get profile of authenticated user
  - `GET  /all-users` - Retrieve all users (Admin only)

- **OTP** (`/api/v1/otp`)
  - `POST /send-otp` - Dispatch OTP to email
  - `POST /verify-otp` - Verify received OTP
